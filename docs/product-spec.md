# 产品需求说明 —— Deep Explorer

> 版本：1.0 | 更新：2026-06-03 | 面向：所有角色（含非技术用户）

---

## 一、项目背景与核心问题

本软件针对三个典型困境：

1. **读了很多，记住很少** —— 缺乏系统提炼，过后遗忘
2. **想深挖，却不知道往哪挖** —— 缺少自动化辅助（反方观点、学术检索、追问生成）
3. **知识积累越来越乱** —— 无行为反馈，不清楚自己的思考模式

Deep Explorer 是一个**主动引导、可量化、可深挖**的探索环境，而非被动笔记工具。

---

## 二、核心理念

| 从 | 到 |
|---|---|
| 手动摘抄 | AI 自动提炼观点 |
| 平铺笔记 | 树状观点（无限层级） |
| 孤立记录 | 三库联动 + 跨库追溯 |
| 模糊感受 | 量化图表（雷达图/趋势图） |
| 被动阅读 | 主动诱导提示 |

## 三、输入范围

### 已支持
| 格式 | 解析库 |
|------|--------|
| PDF | pdfplumber（含页码/段落定位） |
| Word (.docx) | python-docx |
| PPT (.pptx) | python-pptx（文本框+备注） |
| Markdown / 纯文本 | 原生解析 |
| 直接粘贴文本 | 原生 |

### 待开发（欢迎 PR）
- 网页链接直接抓取
- YouTube / 音频转录（时间戳定位）
- 微信公众号 / 付费墙内容
- 扫描版 PDF（OCR，需 Tesseract）

---

## 四、AI 提取模式

### 全自动模式
AI 根据高频实体、结论句、矛盾点、数据引用自动判断价值并提取。

### 半自动模式
用户预设"偏好标签/关键词"，AI 提取时提高相关 Point 的排序权重。

---

## 五、观点（Point）规格

### 数据结构
每个 Point 包含：
- **核心摘要**：一句话
- **类型标签**（自动）：`事实陈述` / `作者观点` / `待验证疑问` / `预测` / `数据引用` / 更多
- **自定义标签**（手动）：如 `重要` / `待查` / `有争议` / `待验证`
- **原文溯源**：高亮片段 + 页码/段落（PDF/Word）或时间戳（未来音视频）
- **层级关系**：`parent_id` 无限嵌套，无层级上限

### 用户编辑权限
允许：增 / 删 / 改 / 合并 / 拆分 任意层级的 Point

---

## 六、深挖动作集

每个 Point 可触发以下动作，结果均可挂载为子 Point：

| 动作 | 触发方式 | 说明 |
|------|----------|------|
| 延伸解释 | 按需点击 | 调用 LLM（API 或 Ollama） |
| 反方观点 | 按需点击 | 调用 LLM 实时生成，不预生成 |
| 本地搜索 | 按需点击 | 在总知识库中语义/关键词匹配 |
| 联网搜索 | 按需点击 | 需用户登录内置代理或配置搜索引擎 API |
| 学术检索 | 按需点击 | arXiv / Crossref / PubMed / Google Scholar / 百度学术 |
| 生成追问 | 按需点击 | LLM 生成 3–5 个延伸问题，可转为子 Point |
| 查找相似 Point | 按需点击 | 在总库中匹配语义相似观点 |
| 导出卡片 | 按需点击 | 导出为图片或 Markdown |

### 搜索关键词生成
自动从 Point 抽取关键词后，**待用户确认/编辑**后再触发搜索。搜索结果可多选并挂载为子 Point。

## 七、三类知识库

### 总知识库
- 永久保存所有入库 Point，支持跨项目检索
- 入库方式：手动批量勾选 + 确认框 + 打标签；或设置中开启自动入库

### 会话库（单次探索）
- 由用户主动"开始一次探索"创建，可命名
- 未手动结束时：当日自动归档，进入**伪归档模式**
- 唤醒：可随时唤醒，日期更新为唤醒当日，**记录唤醒日志**（原归档日期 + 唤醒日期 + 操作次数）

### 项目库（长期课题）
- 用户手动创建，如"2026 ESG 年报"
- Point 可选入总库（同会话库规则）
- 项目结束后归档，支持唤醒并记录时间线
- 项目详情页展示**唤醒时间线图**

### 跨库操作
- 多选 Point → 一键添加到项目库/总库，可同时打标签
- 任意库中查看 Point 时显示来源（哪个会话/项目），可跳转追溯

## 八、行为量化与分析

### 统计维度
| 维度 | 计算方式 |
|------|----------|
| 深度指数 | 对同一 Point 的连续追问次数均值 |
| 广度指数 | 跨不同标签类型的 Point 保存比例 |
| 证据偏好 | 事实类 vs 观点类 Point 保存比例 |
| 反方关注度 | 点击"反方观点"次数 / 总深挖动作次数 |
| 主动搜索率 | 搜索动作次数 / 总深挖动作次数 |
| （可扩展）| 探索时长、唤醒频率、标签分布等 |

### 可视化
- 单次探索：**雷达图**（五维度）
- 历史对比：**折线图**（随会话次数变化）
- 图表在探索结束时生成，支持导出 PNG

---

## 九、探索结束报告

点击"结束本次探索"后生成，包含：
1. **探索路径地图**：树形/流程图展示完整探索轨迹
2. **量化图表**：雷达图 + 折线图（如有历史）
3. **下一步建议**（两种模式并存）：
   - 推荐搜索词（基于知识缺口）
   - 生成问题清单（基于未覆盖子话题）
4. **统计数据**：提取总数、深挖次数、入库数量

---

## 十、中途诱导提示

非侵入式（小弹窗/侧边栏），用户可在设置中关闭或调整灵敏度。

| 触发条件 | 提示内容 |
|----------|----------|
| 连续保存 5 个 Point 无任何深挖 | "要不要试试反方观点，看看另一面？" |
| 停留在同一 Point 超过 3 分钟 | "需要我帮你延伸解释吗？" |
| 搜索后无结果转为 Point | "有几条结果看起来有价值，要保存吗？" |

---

## 十一、本地优先 & 数据主权

- 所有数据存储在本地 SQLite 数据库
- 不向任何服务器上传用户内容
- API Key 本地加密存储
- 提供手动**导出/导入**数据库文件（跨设备迁移）
- 未来可选：加密云备份（WebDAV/S3，由用户自行配置）

---

## 十二、LLM 配置

| 提供商 | 方式 |
|--------|------|
| OpenAI / Anthropic 等 | 用户填入 API Key + 模型名 |
| 本地 Ollama | 自动检测 `localhost:11434`，列出已安装模型 |
| 降级模式 | 不配置 LLM 时，可手动编辑 Point（无 AI 提取） |
