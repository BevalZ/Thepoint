# PRD: 自适应 Point 提取密度

## 问题
提取的 point 数量过多，每段都提取导致信息冗余。

## 解决方案
修改 `SYSTEM_PROMPT`，让模型先判断材料难度，再按密度规则提取：

| 难度 | 密度 |
|------|------|
| 高中水平（科普/新闻） | 200-400字/point，每段≤1 |
| 大学水平（教材/技术博客） | 100-200字/point，每段≤1 |
| 研究生及以上（论文/技术文档） | 50-100字/point |
| 科技类工具介绍/章节 | 整栏目/小节 1 个 point |

"宁少勿多"：跳过过渡句、举例、重复表述。

## 改动
- `src-tauri/src/ai/openai.rs`: 替换 `SYSTEM_PROMPT`
